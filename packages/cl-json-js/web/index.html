cl-json-js web example

This page is served from packages/cl-json-js/web by the module's own instance (npm run server -w @setmy-info/cl-json-js) on the port from its resources/application.yaml. Every section below is a JSON-CL file in pages/, loaded, evaluated and put into the DOM - by a <script type="application/cl+json" src> tag, or by calling ClJson.include(). Serve this folder over HTTP: browsers do not let a page opened from disk read files.
