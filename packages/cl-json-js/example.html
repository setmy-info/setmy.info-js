cl-json-js examples

Each example is Common Lisp written as JSON (CL-WHO style HTML plus cl: forms). On the left is the source, on the right the live DOM it produces. Edit the source and the result updates as you type. Click around: event handlers change state with cl:setf / cl:incf and the view re-renders.
